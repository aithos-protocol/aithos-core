# aithos-core

Pure, deterministic protocol logic for Aithos identities, mandates,
delegation, revocation, receipts, gamma logs, and publication facts.

This crate performs no I/O, reads no clock, draws no entropy, and accesses no
network. Time, randomness, and storage are injected by callers.

Status: pre-release. The wire protocol remains a draft.
