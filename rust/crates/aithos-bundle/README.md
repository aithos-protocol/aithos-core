# aithos-bundle

Bundle layout, storage abstraction, mutation, publication, and verification
for Aithos Core.

`aithos-bundle` is the I/O boundary over the pure `aithos-core` protocol
engine. The first release is a pre-release and the wire protocol remains a
draft.
