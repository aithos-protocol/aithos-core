La réponse est bornée par la clé utilisée : via la clé owner, l'agent peut tout révéler ; via un mandat, il ne répond que dans le périmètre du mandat.

Cycle de vie

Suspendre
Coupe l'action au niveau tool-host / heartbeat. Réversible, les clés restent — ce n'est pas une coupe crypto.
Révoquer & supprimer
Rotation de la clé du nœud + re-chiffrement (échelle §06). Coupe cryptographique, cascade sur les sous-mandats. Irréversible.

Gateway · Coffre

Les credentials (identifiants, mots de passe, tokens OAuth) vivent ici, dans le coffre de la gateway — jamais dans l'agent. Un agent ne reçoit qu'un scope d'action (act.x.<id>.<action>) ; il présente son mandat, la gateway ouvre le secret et exécute. Le secret ne quitte jamais le coffre (invariant I1 · guardian = tool-host §08.2).

Séparation nette : Coffre (secrets) côté gateway · Agent (clés + mandat) côté runtime. Compromettre un agent n'expose aucun credential.
